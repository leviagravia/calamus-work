1. FAILURE LEDGER AND CLASSIFICATION
------------------------------------

The W90 work item accumulated seven failed or retired candidate cycles before R7:

1. initial candidate: historical W85 GTK regression exposed monolithic display-test fragility;
2. first reconstruction: historical W89 identity test incorrectly asserted current metadata;
3. R2: post-close verifier imposed a hard-coded output path;
4. R3: old multi-dialog true-App driver returned False after its own timeout/cancel;
5. R4: repeated the same driver architecture and the same False;
6. R5: fixed true-App handoff, but desktop validator again confused a suggested path with product correctness; manual artifacts then exposed the real BibLaTeX literal-list defect;
7. R6: product serialization was corrected, but a true-App assertion compared the raw plain-text substring `Herder and Herder`. Pandoc 3.1.3 rendered the semantically correct value as `Herder and\nHerder` because the plain writer wraps output. The test failed before desktop validation.

R6 ThinkPad evidence:
- all compile/headless/provenance/scope/GTK-boundary and historical lanes passed;
- real App/controller/store/Pandoc lane produced the correct publisher words;
- failure was exactly:
    expected raw contiguous substring: Herder and Herder
    actual plain writer output:         Herder and\nHerder
- no semicolon appeared;
- rollback to W89 passed.

Classification:
- R5 `Herder; Herder`: PRODUCT DATA-FIDELITY FAIL;
- R6 `Herder and\nHerder`: TEST SEMANTIC-COMPARISON FAIL;
- R6 did not prove a product regression and must not be patched by changing Pandoc output or disabling wrapping.

  - the plain bibliography test still used line-layout-sensitive raw substring checks for titles and did not exercise publisher wrapping.

- `tests/test_w90_pandoc_app_desktop_e2e.py`

- the gate lacked one explicit normalization policy separating layout variability from punctuation/list semantics.

3. DIRECT PANDOC SOURCE AUDIT
-----------------------------

Archive: `pandoc-main.zip`

Files/functions inspected:

- `src/Text/Pandoc/Citeproc/BibTeX.hs`
  - `getLiteralList'()` parses BibLaTeX literal-list fields;
  - `splitByAnd` splits only the inline token sequence space + `and` + space;
  - publisher list items are rejoined with semicolon-space for CSL data.
  - Therefore `publisher = {Herder and Herder}` becomes two items, while the extra protected group keeps one item.

- `src/Text/Pandoc/Writers/Markdown.hs`
  - `writePlain()` delegates to the Markdown writer in `PlainText` mode;
  - `pandocToMarkdown()` uses `writerColumns` when `writerWrapText == WrapAuto`.

- `src/Text/Pandoc/Options.hs`
  - `WrapAuto` explicitly means automatic wrapping to width;
  - `WrapNone` means no nonsemantic newlines.

- `src/Text/Pandoc/App/Opt.hs`
  - default CLI options are `WrapAuto` and 72 columns.

Consequences:
- a newline inserted between `and` and `Herder` is a permitted writer-layout transformation;
- punctuation remains semantic: `Herder; Herder` is still different from `Herder and Herder` after whitespace normalization;
- changing W90 argv to `--wrap=none` would hide a brittle test instead of fixing the verifier and would unnecessarily change the product output policy.

Decision:
- ADOPT semantic verification after NFC + whitespace-run collapse;
- RETAIN punctuation exactly;
- REJECT raw contiguous-substring gates on rendered plain text;
- REJECT changing Pandoc wrapping solely to satisfy tests.

8. R7 ADOPT / ADAPT / REJECT / DEFER
------------------------------------

ADOPT
- retain R6 literal-list serialization fix;
- one test-only semantic artifact normalizer:
  1. require `str`;
  2. Unicode NFC normalization;
  3. collapse every whitespace run to one ASCII space;
  4. optional casefold only for case-insensitive bibliographic identity checks;
  5. preserve punctuation and word order;
- use the same policy in real-Pandoc controller tests, true-App real-Pandoc tests and desktop artifact verification;
- explicit regression cases for LF/CRLF wrapping, case differences and semicolon corruption;
- real Pandoc plain bibliography and ODT evidence;
- exact canonical-input hashes, staging cleanup and lifecycle gates.

ADAPT
- test helper lives under `tests/`, not in production modules;
- desktop verifier embeds the same narrow algorithm because it must remain a standalone shell/Python runner;
- scope gate rejects any return to raw `assertIn("Herder and Herder", rendered)`.

REJECT
- `--wrap=none` as a test workaround;
- replacing `and`, semicolons or punctuation before comparison;
- fuzzy matching, token sorting or edit-distance acceptance;
- casefold for publisher punctuation fidelity;
- changing the correct R6 product serializer;
- hard-coded output destinations;
- another manual test before automated true-App passes.

DEFER
- generalized CSL-aware semantic equivalence;
- multi-valued publisher/location in the Calamus canonical model;
- any W91 work.
