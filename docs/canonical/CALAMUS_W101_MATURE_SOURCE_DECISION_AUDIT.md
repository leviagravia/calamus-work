# W101 mature-source decision authority

This record applies the completed direct-source R1/R2/R3 audits; it does not
replace them with web material.

- GNOME Text Editor: **ADOPT** hierarchical lifetime ownership; **REJECT**
  default/global lookup.
- Airpad: **ADAPT** responsibility-specific modules; **REJECT** application-data
  bags.
- Helix: **ADOPT** enforceable dependency direction; **REJECT** global event/job
  registries.
- NotepadNext: **ADOPT** local manager/factory ownership and weak cleanup;
  **REJECT** whole-main-window dependencies.
- Geany: **ADOPT** startup-complete and reverse teardown topology; **REJECT**
  global widget/document data.
- Kate: **ADOPT** thin launcher and distinct manager responsibilities;
  **DEFER** action collections to W105.
- Pluma/gedit: **ADAPT** explicit factories; **REJECT** singleton/plugin/fat
  window architecture.
- Bluefish: **REJECT** `Tmain`/`Tbfwin`/`Tdocument` data bags and public internal
  structure contracts.
- Micro: **ADOPT** buffer/view and stable command identity evidence; **REJECT**
  global registries and generic callback cycle repairs.
- Neovim: **ADAPT** owned asynchronous queues and ordered teardown; **REJECT**
  current-buffer/window globals and generic event bus.
- Monaco: **DEFER** layer/contribution lessons to W105/W108; **REJECT** its
  extension framework for Calamus.

W101 therefore uses a stateless root, local builders, frozen ownership bundles,
explicit inputs, named set-once local cycles, and executable AST direction gates.
